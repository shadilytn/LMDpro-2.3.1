# SPEC-KIT: 06-REMEDIAL-ASSESSMENT

## 1. Feature Overview
The **Diagnostic Gaps & AI Remedial Assessment** module automatically tracks student progress, highlights skill gaps, dynamically generates tailored diagnostic questions, and synthesizes structured custom remedial packages to accelerate learning.

---

## 2. Problem Statement & Target Persona
Traditional assessments are uniform and static, forcing students through redundant testing. Advanced executive learners require precise diagnostic checkups that identify specific conceptual weaknesses and deliver instant targeted learning materials to bridge those gaps.

---

## 3. Object-Oriented Technical Architecture

### 3.1 Class & Component Interface Blueprint

```typescript
interface ISkillGap {
  topicId: string;
  topicTitle: string;
  confidenceScore: number; // Percentage from 0 to 100
  unresolvedConcepts: string[];
}

interface IRemedialPackage {
  packageId: string;
  targetTopicId: string;
  summaryExplanation: string;
  recommendedResources: Array<{ title: string; url: string; type: string }>;
  remedialQuizQuestions: Array<{
    id: string;
    questionText: string;
    choices: string[];
    correctIndex: number;
    conceptualHint: string;
  }>;
}

class AdaptiveLearningEngine {
  private studentScores: Record<string, number[]> = {}; // Map of topicId to array of historical percentage scores

  public analyzeSkillGaps(topics: string[]): ISkillGap[] {
    const gaps: ISkillGap[] = [];
    for (const topic of topics) {
      const scores = this.studentScores[topic] || [];
      const avgScore = scores.length > 0 ? scores.reduce((a, b) => a + b, 0) / scores.length : 100;
      if (avgScore < 80) {
        gaps.push({
          topicId: topic,
          topicTitle: topic,
          confidenceScore: Math.round(avgScore),
          unresolvedConcepts: this.identifyWeakConcepts(topic)
        });
      }
    }
    return gaps;
  }

  private identifyWeakConcepts(topicId: string): string[] {
    // Queries specific diagnostic logs to pinpoint subtopics
    return ["Equation derivation", "Kinetic energy matrices"];
  }
}
```

### 3.2 Component Manifest
- **`AdaptiveQuizEngine.tsx`**: Dynamic quiz workspace rendering interactive multiple-choice questions, diagnostic evaluations, and socratic scoring reviews.
- **`AIContentCurationEngine.tsx`**: Highlights diagnosed skill gaps and lets users trigger custom remedial content generation on the fly.
- **`MentorFeedbackOverlay.tsx`**: Translucid card overlay giving detailed feedback and recommendations.

## 4. User Stories & Acceptance Criteria

### User Story 1: Dynamic Diagnostic Tracking
> **As an** advanced student preparing for certification,  
> **I want to** view my conceptual skill gaps displayed with visual confidence scores,  
> **So that** I know exactly which subtopics require study focus.

- **Acceptance Criterion 1.1**: The system must track historical test/quiz records per topic and calculate active confidence ratings.
- **Acceptance Criterion 1.2**: Skill gaps must be highlighted clearly within the UI using intuitive, high-contrast visual meters.

### User Story 2: On-Demand Remedial Compilation
> **As a** student with identified aerodynamic math gaps,  
> **I want to** trigger a custom learning pack generated by Petra,  
> **So that** I can study tailored explanations and attempt focused practice drills.

- **Acceptance Criterion 2.1**: Clicking "Generate Remedial Pack" must send the specific gap parameters to the backend AI services.
- **Acceptance Criterion 2.2**: The generated package must include executive-level summaries, curated learning links, and focused diagnostic drills.

## 5. Automated Verification & QA
- **Parsing Robustness**: Ensure that the dynamically synthesized questions utilize strict schemas so that the quiz parser never renders corrupted choices or missing index values.
- **Responsive Sizing**: The quiz board must transition elegantly to vertical stacks on small device sizes to preserve finger-friendly touch targets ($\ge 44\text{px}$).
