Every application generated or orchestrated by the system MUST follow the **Hybrid Agentic Engine Architecture**:

### 3.1 Cognitive Layer
1. **Macro-Engine (Cloud) - Gemini 3.1 Flash-Lite / 3.1 Pro**: High-level intent parsing, global task planning, public data scraping, and code compilation.
2. **Micro-Engine (Edge) - Nano Banana Pro**: Local WASM/WebGPU inference, real-time DOM matching, and zero-latency PII redaction directly inside the user's browser.

### 3.2 Action Layer
1. **Server-Side Remote Execution (Steel.dev / Playwright)**: Headless containerized browser fleet for massive parallel scraping of public web data.
2. **Client-Side Domestic Execution (rtrvr.ai / Rover SDK)**: Client-injected execution operator that leverages the user's local IP and authenticated browser cookies to safely bypass anti-bot walls without sharing private credentials.

## 4. Operation Security & Static Abstract Syntax Tree (AST) Validation

To safely execute dynamically generated Python scripts within cloud-hosted headless Blender environments (using Model Context Protocol socket bridges) or browser-side Pyodide sandboxes, Zalamati MUST pass all generated scripts through strict static AST validation:

1. **Allowed Modules**: `bpy`, `math`, `mathutils`, `bmesh`, `numpy`, `sympy`.
2. **Forbidden Built-ins & Modules**: `os`, `sys`, `subprocess`, `socket`, `requests`, `exec`, `eval`, `compile`, `open`, `input`, `__import__`.
3. **Namespace Sandboxing**: Executed strictly inside isolated global contexts with restricted builtin dictionaries.
