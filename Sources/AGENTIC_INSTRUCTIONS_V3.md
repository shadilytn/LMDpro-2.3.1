## 1. Operation Security: Abstract Syntax Tree (AST) Validation

To safely execute dynamically generated Python scripts within cloud-hosted headless Blender environments (using Model Context Protocol socket bridges) or browser-side Pyodide sandboxes, **Zalamati** must pass all generated scripts through this strict AST validation process before routing:

1.  **Parse to AST:** Convert the generated string payload into an AST tree utilizing `ast.parse()`.
2.  **Allowed Modules Check:** Restrict imports exclusively to a safe computational and modeling namespace: `bpy`, `math`, `mathutils`, `bmesh`, `numpy`, and `sympy`.
3.  **Forbidden Built-ins and Calls Check:** Systematically block any system execution commands or dynamic evaluators: `os`, `sys`, `subprocess`, `socket`, `requests`, `exec`, `eval`, `compile`, `open`, `input`, and `__import__`.
4.  **Enforce Restricted Execution Global Context:** Execute approved scripts only within a sandboxed context where the global builtins dictionary is replaced with a restricted set of safe mathematical primitives.

### Validator and Sandboxed Harness Script (Zalamati Execution Core)

```python
import ast
import math

class SecurityViolationError(Exception):
    pass

class SafeCodeValidator(ast.NodeVisitor):
    # Restrict modules exclusively to approved math and mesh libraries
    ALLOWED_MODULES = {'bpy', 'math', 'mathutils', 'bmesh', 'numpy', 'sympy'}
    # Explicitly forbid standard OS-level builtins and dynamic runtimes
    FORBIDDEN_BUILTINS = {'exec', 'eval', 'compile', 'open', '__import__', 'input'}

    def visit_Import(self, node):
        for alias in node.names:
            base_module = alias.name.split('.')[0]
            if base_module not in self.ALLOWED_MODULES:
                raise SecurityViolationError(f"Security Policy Violation: Unauthorized import '{alias.name}'")
        self.generic_visit(node)

    def visit_ImportFrom(self, node):
        if node.module:
            base_module = node.module.split('.')[0]
            if base_module not in self.ALLOWED_MODULES:
                raise SecurityViolationError(f"Security Policy Violation: Unauthorized from-import '{node.module}'")
        self.generic_visit(node)

    def visit_Call(self, node):
        # Prevent calling forbidden builtins
        if isinstance(node.func, ast.Name):
            if node.func.id in self.FORBIDDEN_BUILTINS:
                raise SecurityViolationError(f"Security Policy Violation: Forbidden builtin call '{node.func.id}()'")
        
        # Prevent calling dynamic import attributes (e.g., importlib, sys.modules)
        elif isinstance(node.func, ast.Attribute):
            if node.func.attr == '__import__':
                raise SecurityViolationError("Security Policy Violation: Forbidden attribute access '__import__'")
                
        self.generic_visit(node)

def validate_and_execute_code(script_contents: str, bpy_instance):
    """
    Parses script into an Abstract Syntax Tree, runs policy verification,
    and executes inside a sandboxed global context.
    """
    # Step 1: Static AST Validation
    try:
        parsed_ast = ast.parse(script_contents)
        validator = SafeCodeValidator()
        validator.visit(parsed_ast)
    except SyntaxError as e:
        raise SecurityViolationError(f"Script Syntax Error: {e.msg} at line {e.lineno}")
    
    # Step 2: Namespace Sandboxing
    safe_builtins = {
        'range': range, 'len': len, 'int': int, 'float': float, 'str': str,
        'list': list, 'dict': dict, 'set': set, 'tuple': tuple, 'zip': zip,
        'enumerate': enumerate, 'abs': abs, 'min': min, 'max': max, 'print': print
    }
    
    restricted_globals = {
        '__builtins__': safe_builtins,
        'bpy': bpy_instance,
        'math': math
    }
    
    # Step 3: Run inside isolated context
    exec(script_contents, restricted_globals, {})
```
