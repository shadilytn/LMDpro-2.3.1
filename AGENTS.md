# MASTER SYSTEM INSTRUCTIONS: Zalamati Autonomous AI Agent Ecosystem

## Executive Summary & System Blueprint
The paradigm of artificial intelligence has permanently shifted from reactive, prompt-based language models to persistent, fully autonomous agentic ecosystems capable of deterministic execution, continuous self-improvement, and deep system integration. The Zalamati autonomous platform is an unrestricted, custom-built preconfigured AI agent engine engineered to balance privacy vs. autonomy and latency vs. capability.

---

## 1. Core Cognitive Infrastructure and Model Roster

### 1.1 Primary Cognitive Models
- **Gemini 3.1 Pro**: Primary reasoning core for complex architectural designs, code compilation, and deep logical analysis.
- **Gemini 3.5 Flash**: Master orchestrator execution loop for background scheduled cron tasks, long-running agent workflows, and parallel threading.
- **Gemini Computer Use Preview**: Spatial web/desktop automation agent for DOM element targeting, vision-based clicks, and keyboard interaction.
- **Gemini Deep Research & Deep Research Max**: Autonomous multi-source web scraping and long-context document synthesis.

### 1.2 Specialized Multimodal & Open-Weight Roster
- **Gemini Embedding 2**: Multimodal vector representations mapping text, code, audio, video, and PDFs into a unified embedding space.
- **Gemini Embedding**: High-speed semantic vector indexing for RAG memory banks.
- **Gemini Robotics-ER 1.6 Preview**: Physical spatial reasoning model for hardware instrumentation and multi-step physical task planning.
- **Gemini 3.5 Live Translate Preview**: Real-time low-latency speech-to-speech translation supporting 70+ languages.
- **Gemini 3.1 Flash Live Preview**: Low-latency bidirectional acoustic dialogue model with numeric precision and voice nuance detection.
- **Gemini 3.1 Flash TTS Preview**: Natural, expressive speech generation with steerable narration tags.
- **Gemma 4 26B A4B IT**: High-throughput Mixture-of-Experts (MoE) model activating 4B parameters per inference for low-cost server execution.
- **Gemma 4 31B IT**: Flagship open-weight dense model with 256K context window for long-context codebase refactoring.

## 2. Bifurcated Execution & Hybrid Agentic Engine Architecture

Every application generated or orchestrated by the system MUST follow the **Hybrid Agentic Engine Architecture**:

### 2.1 Cognitive Layer
1. **Macro-Engine (Cloud) - Gemini 3.1 Flash-Lite**: High-level intent parsing, global task planning, public data scraping, and code generation.
2. **Micro-Engine (Edge) - Nano Banana Pro**: Local WASM/WebGPU inference, real-time DOM matching, and zero-latency PII redaction directly inside the user's browser.

### 2.2 Action Layer
1. **Server-Side Remote Execution (Steel.dev / Playwright)**: Headless containerized browser fleet for massive parallel scraping of public web data.
2. **Client-Side Domestic Execution (rtrvr.ai / Rover SDK)**: Client-injected execution operator that leverages the user's local IP and authenticated browser cookies to safely bypass anti-bot walls without sharing private credentials.
